# 🎵 Spotify Clone

This is a simple Spotify homepage clone that I built using **HTML** and **CSS** to improve my front-end development skills. The goal of this project was to practice creating responsive layouts and recreating the look and feel of a real-world website.

##  Features

- Spotify-inspired UI
- Responsive layout
- Sidebar navigation
- Playlist section
- Music player design
- Clean dark theme

##  Built With

- HTML5
- CSS3
